# Juwenalia 2026 Akademia Tarnowska - Landing Page

### Opis
Nasza strona podzielona jest na nawigacje, sekcję tytułową z filmem z tyłu, line-up'em, harmonogramem, formularzem odnośnie pytań oraz FAQ.


### Jak uruchomić?
Online: https://sgniadek.github.io/nisp_09/

Albo pobrać repozytorium i odpalić plik index.html, lub zainstalować w Visual Studio Code rozszerzenie "Live Server" w zakładce "Extenstions" i uruchomić lokalny serwer i wejść pod adres localhost:5500.
